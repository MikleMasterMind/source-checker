# source-checker

Консольная утилита на Python для проверки скорости скачивания: она делает несколько
**последовательных** GET-запросов к указанному URL (например, к «тяжёлой» картинке),
дожидается **полного** ответа на каждый из них и выводит:

- среднее время запроса;
- общий объём скачанных данных;
- среднюю скорость скачивания.

## Запуск

Нужен только [uv](https://docs.astral.sh/uv/getting-started/installation/) — нужная версия
Python и зависимости будут установлены автоматически:

```bash
uv run main.py https://example.com/heavy-image.jpg
```

### Параметры

| Параметр | Описание |
|---|---|
| `URL` | адрес, по которому стучаться (обязательный) |
| `-n`, `--requests N` | количество последовательных запросов (по умолчанию 10) |
| `--timeout S` | максимальное время одного запроса в секундах (по умолчанию 30); не дочитанный за лимит запрос помечается `FAIL` |

Примеры:

```bash
# 5 запросов вместо 10
uv run main.py -n 5 https://example.com/heavy-image.jpg

# поднять лимит времени одного запроса до 60 секунд
uv run main.py --timeout 60 https://example.com/heavy-image.jpg
```

### Единицы измерения

- время — секунды (значения меньше секунды — в миллисекундах, больше минуты — в минутах и секундах);
- объём — десятичные единицы: **1 KB = 1 000 байт, 1 MB = 1 000 000 байт, 1 GB = 1 000 000 000 байт**;
- скорость — **MB/s** (десятичные мегабайты в секунду), дополнительно в **Mbps**
  (мегабитах в секунду; 1 MB/s = 8 Mbps).

### Поведение при ошибках

Упавший запрос (сетевая ошибка, не-2xx статус, превышение лимита времени) помечается
как `FAIL` и пропускается, остальные выполняются как обычно. Итоговая статистика
считается по успешным запросам. Прогон можно прервать `Ctrl+C` — накопленная частичная
статистика будет напечатана.

Коды возврата:

- `0` — есть хотя бы один успешный запрос;
- `1` — успешных запросов нет;
- `2` — неверные аргументы;
- `130` — прогон прерван `Ctrl+C`.

## Как это работает

1. Скрипт открывает один HTTP-клиент (`httpx`) с включёнными редиректами и собственным
   User-Agent (`source-checker/...`): некоторые хосты, например Wikimedia, отклоняют
   запросы с дефолтным User-Agent библиотеки.
2. Каждый запрос стримится по чанкам до последнего байта — время меряется от старта
   запроса до полного завершения ответа (`time.perf_counter`). `--timeout` задаёт
   жёсткий лимит на длительность **всего** запроса: не дочитанный за лимит ответ
   обрывается и помечается `FAIL` (таймауты httpx дополнительно страхуют от
   зависших соединений).
3. Средняя скорость = суммарный объём всех успешных ответов / суммарное время этих
   ответов. Запросы выполняются строго последовательно, поэтому измеряется «чистая»
   скорость одного соединения без параллелизма.
